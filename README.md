# Vital Apex — Demo

Demo funcional: https://gribeir0.github.io/vital-apex-demo/

- Totem: identificação, cadastro fictício, agenda, pagamento simulado e confirmação.
- Painel: pagamentos, filtros, comprovantes e catálogo fictício.
- CPF fictício: **529.982.247-25**.
- Painel: **demo@vitalapex.local** / **DemoVital2026!** (acesso exclusivamente demonstrativo).

Sem APIs, prontuários, banco remoto, fontes externas ou cobranças. PIX/cartão aprovados automaticamente após duas consultas (aproximadamente 6 segundos). Os pedidos fictícios ficam no armazenamento local deste navegador; o cadastro informado é descartado pelo simulador. Não informe dados reais.

Abra totem e painel no mesmo navegador. Use **Reiniciar demonstração** para restaurar os exemplos. A recepção inicia sem pendências. Jornada e preços são somente consulta. Nenhuma integração real é demonstrada.

Este repositório contém somente os arquivos estáticos da demo. O sistema original permanece privado.
